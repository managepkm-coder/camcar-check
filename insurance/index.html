데이터는 이 기기에만 저장돼요. 백업 파일을 카톡 등으로 보내고 다른 폰에서 ‘불러오기’를 누르면 같은 화면을 볼 수 있어요.

보험 목록 자동으로 불러오기?

뱅크샐러드·토스는 금융위원회 마이데이터 허가를 받은 회사만 쓸 수 있는 통로로 보험사 데이터를 받아와요. 개인이 만든 앱은 이 통로를 쓸 수 없어서 자동 연동은 안 돼요. 대신

  1. 내보험다보여(신용정보원) ↗에서 본인 명의 보험을 한 번에 조회해 옮겨 적기 (가족은 각자 본인인증)
  2. 보험 앱 화면이나 보험증권을 ‘사진으로 등록’ (폰 안에서 무료로 글자 인식)
  3. 보험 앱의 ‘○% 납부 · ○원 남음’ 숫자로 납입기간 계산하기 (보험 추가 화면)
  4. 엑셀 양식에 한꺼번에 적어서 ‘불러오기’

글자 붙여넣기

손글씨는 폰 글자 인식이 잘 못 읽어요. 아래 중 편한 방법으로 글자를 복사해 붙여넣으면 보험을 찾아 드려요.

  1. 삼성 갤러리: 사진 열기 → 오른쪽 아래 T(텍스트 추출) → 모두 선택 → 복사
  2. Google 렌즈: 사진에서 텍스트 → 모두 선택 → 복사
  3. Claude 앱(구독 중이면 추가 비용 없음): → Claude 앱에 사진과 함께 보내기 → 받은 표를 복사
