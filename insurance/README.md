# 우리집 보험 (insurance/)

가족 보험의 **월 납입액**과 **납입기간**을 한 화면에 보여 주는 웹 앱입니다.
근무표 앱처럼 광고도 서버도 없고, 데이터는 이 기기(localStorage)에만 저장됩니다. (가족 실시간 공유를 켜면 주인의 Firebase에도 저장)

주소: `https://<사용자>.github.io/camcar-check/insurance/` (main에 합쳐지면 자동 배포)
폰에서 **홈 화면에 추가**하면 앱처럼 열리고 오프라인에서도 동작합니다.

## 화면

| | |
|---|---|
| **납입기간 한눈에** | 노트에 그리던 표 그대로. 보험마다 납입기간 막대, 끝나는 해와 그때 나이, 오른쪽 열에 월납입액, 맨 아래 합계. 파란 세로선이 오늘 |
| **보험별 상세** | 보험사 앱처럼 카드마다 월 보험료, 납부율 막대, 남은 금액, 완납까지 남은 기간 |
| **요약** | 가족 전체 월 보험료, 사람별 비중, 지금까지 낸 돈, 앞으로 낼 돈 |
| **보험료가 줄어드는 때** | 보험이 하나씩 완납될 때마다 월 보험료가 얼마로 줄어드는지 |
| **받을 연금·만기금** | 연금 받기 시작하는 해, 기간, 월 수령액 |
| **해지한 보험** | 해지한 달을 넣으면 합계에서 빠지고 따로 모아 보여 줌 |
| **받은 보험금** | 병원비·진단금 등 받은 날·금액·내용을 기록하면 합계(납부한 금액 대비 %), 사람별, 날짜순 목록, 보험별 카드, 타임라인의 ◆ 로 보여 줌. 내용 빠른 선택은 여러 개 고를 수 있음(‘입원비, 수술비’) |
| **보장 한눈에** | 보험마다 넣은 보장내용을 사망·후유장해·암·유사암·뇌혈관·심장·수술비·입원비·실손·골절·간병·운전자·배상책임·치아로 나눠 가족별 표로 더해 보여 줌. 기본 보장(사망·암·뇌·심장·실손)이 빠졌으면 빨간 ‘없음’, 줄을 누르면 어느 보험의 어떤 보장인지 펼쳐 봄 |

위쪽 칩(전체 · 본인 · 배우자 …)으로 사람별로 걸러 볼 수 있습니다.
보험을 다른 사람 것으로 옮기려면 *보험별 상세* 카드 오른쪽 위의 이름(⇄)을 누르거나, 보험 수정 화면의 *다른 사람 보험으로 옮기기*를 누릅니다. 받은 보험금과 알림도 같이 옮겨집니다.
같은 보험을 다른 가족도 들었다면 보험 수정 화면의 *다른 사람 보험으로 복사하기*로 똑같이 하나 더 만든 뒤 금액만 고치면 됩니다(보장내용은 같이 복사, 받은 보험금·보험료 변경 기록·해지 예정일·확인한 적립금은 복사하지 않음).
가족 보험 화면의 *내 보험으로 복사하기*는 사람을 고르지 않고 바로 본인(맨 앞 가족) 보험으로 복사합니다. 가족 장부를 **보기만** 하는 중에도 이 버튼은 쓸 수 있고, 이때는 그 보험이 이 폰의 *내 장부*로 복사됩니다(가족 장부는 그대로, *그만 보기*로 내 장부에 가면 보임).

## 넣는 법

- **📷 사진으로 등록 (무료)**: 보험 앱 캡처나 보험증권 사진(한 번에 5장까지)을 고르면 **폰 안에서** 글자를 읽어(OCR, [tesseract.js](https://github.com/naptha/tesseract.js) 7.0.0) 보험사·월 납입액·납부율·남은 금액을 채웁니다.
  사진은 밖으로 나가지 않고 비용도 없습니다. 처음 한 번 인식 데이터(약 5MB)를 jsDelivr에서 내려받습니다.
  확인 화면에서 고친 뒤 등록하며, 이미 등록된 보험은 중복으로 표시해 기본으로 빼 둡니다.
- **📋 글자 붙여넣기**: 손글씨는 폰 OCR이 못 읽으므로, 삼성 갤러리 *텍스트 추출*·Google 렌즈로 복사한 글자나
  Claude 앱에 사진을 주고 받은 표(앱 안의 *요청문 복사* 사용)를 붙여넣으면 같은 확인 화면으로 갑니다.
- **＋ 보험 추가**: 보험사, 월 납입액, 납입 시작(계약일, 일자까지), 납입 기간(년) 또는 납입 끝 월.
  이번 달 보험료는 이체일(없으면 납입 시작 일자)이 지나야 낸 것으로 계산합니다.
  실손처럼 끝 없이 내는 보험은 **갱신형**에 체크합니다. 시작 월을 모르면 비워도 됩니다(끝 월로 남은 금액만 계산).
- **일시납**: 변액보험처럼 처음에 한 번 큰돈을 내고 매달 따로 내는 경우, *일시납* 금액과 날짜(비우면 납입 시작일)를 넣으면 총 납부할 금액·납부한 금액·남은 납부액에 더해집니다(월 보험료에는 안 들어감). 월납 없이 일시납만 낸 보험도 등록할 수 있습니다.
- **보험료가 오르는 보험(실손 등)**: *갱신형 · 끝 없음*으로 넣고, 오를 때마다 보험 화면의 *보험료가 바뀌었어요*에 새 금액과 바뀐 달을 기록합니다. 그 전 달까지는 예전 금액으로 더해서 납부한 금액이 정확합니다. 납입액 칸을 직접 바꾸면 ‘이번 달부터 오른 것’인지 ‘처음부터 잘못 넣은 것’인지 묻습니다.
- **저축 보험 적립금**: *저축 · 적립금*에서 *저축되는 보험*을 켜면 낸 돈 × 적립 비율(기본 95%, 사업비 제외)을 연 이율(기본 2.5%)로 달마다 불려 예상 적립금과 연금 시작(또는 납입 끝) 때 예상액을 보여 줍니다. 보험사 앱에서 본 적립금과 날짜를 넣으면 그 값에서 계산합니다(변액보험은 꼭 넣기). 추정치이므로 실제 금액은 보험사에서 확인하세요.
- **보장내용**: 보험 화면의 *보장내용*에서 *＋ 추가*(보장 이름 · 금액 · 분류 · 메모). 분류는 이름으로 자동으로 정하고(‘암 수술비’는 수술비, ‘(유사암 제외)’ 같은 괄호 안은 무시), 금액은 *+1억 / +1,000만 …* 버튼으로도 넣습니다. 금액을 비우면 ‘가입’으로 보여 줍니다.
  *📋 한꺼번에*: 보험증권의 보장내용 표를 **사진으로 읽거나**(폰 안 OCR, 무료) 복사한 글자를 붙여넣으면 줄마다 ‘이름 … 첫 금액’을 찾아 확인 화면에 보여 줍니다(보험료 줄·계약자 같은 줄은 빼고, ‘100세만기’ ‘20년갱신’은 메모로, 이미 넣은 보장은 체크를 빼 둠).
  ‘보장 한눈에’에서 진단비·사망 등은 여러 보험을 **더하고**, 실손은 여러 개여도 실제 병원비를 나눠 받으므로 **가장 큰 한도**를, 입원비는 **하루 금액**을 보여 줍니다. 종류가 ‘실손’인 보험은 보장내용을 안 넣어도 ‘가입’으로 표시합니다.
  엑셀(CSV)에는 *보장내용* 칸에 `일반암 진단비 3,000만원; 질병통원의료비 20만원 (회당)` 처럼 들어가고 불러올 때 다시 읽습니다. 보험을 다른 사람에게 복사하면 보장내용도 같이 복사됩니다.
- **‘○% 납부 · ○원 남음’만 아는 경우**: 토스·뱅크샐러드·보험사 앱에 나오는 두 숫자를 넣으면 시작과 끝을 계산해 채워 줍니다.
- **엑셀로 한꺼번에**: 설정 → *엑셀 입력 양식*을 받아 채운 뒤 *불러오기*. 엑셀 기본 CSV(EUC-KR)도 읽습니다.
- **가족 출생 연도**를 넣으면 타임라인에 그 해의 나이가 표시됩니다.

## 알림

**알림** 카드(또는 보험 수정 화면의 *＋ 알림*)에서 날짜·시각·반복(한 번/매달/매년)·미리 알림(당일/하루 전/3일 전/일주일 전)을 정합니다.
빠른 선택(해지할 날·갱신일·납입 끝나는 날·보험금 청구·연금 받기 시작)은 고른 보험의 정보로 날짜와 반복을 채웁니다.

**해지할 날짜**: 보험 수정 화면의 *해지할 날짜*에 날짜를 적으면 그 보험의 해지 알림(일주일 전 + 당일)이 자동으로 생기고 바로 캘린더에 넣을 수 있습니다.
카드·타임라인(빨간 세로선)·‘보험료가 줄어드는 때’에 해지 예정이 표시되고, 그날이 되면 맨 위 배너를 눌러 *해지했어요* 로 해지 처리합니다.
보험 화면 맨 위 해지 예정 상자의 *날짜 바꾸기*로 날짜를 고치고, 날짜 칸 옆 *지우기*로 해지 예정을 없앨 수 있습니다(폰 날짜 창에 지우는 버튼이 없어도 됨). 이미 해지한 보험은 같은 자리의 *달 바꾸기*·*해지 취소*로 고칩니다.

서버가 없는 웹앱은 닫혀 있을 때 직접 폰 알림을 보낼 수 없으므로, 저장한 알림을 **폰 캘린더에 넣어** 캘린더가 알리게 합니다.
- *삼성 캘린더 등에 넣기*: 알림이 담긴 `.ics` 파일을 받습니다 → 알림창/다운로드에서 열기 → 캘린더 앱에서 저장. 반복·미리 알림이 함께 들어갑니다.
- *Google 캘린더로 열기*: 일정 추가 화면이 열립니다(알림 시점은 구글 캘린더 기본 설정).
- 앱을 열면 다가온 알림이 맨 위에 *🔔 오늘 / D-3* 으로 뜹니다.

## 가족과 같이 보기

### 실시간 공유 (초대받은 가족은 보기만)

설정 → **가족 실시간 공유**. 무료 Google **Firebase**(Authentication + Firestore)에 장부 문서 하나를 올려 공유합니다.
누가 무엇을 할 수 있는지는 [`firestore.rules`](firestore.rules)가 정합니다: 주인만 고치고, 초대 코드로 들어온 사람은 자기 자신만 ‘보는 사람’에 넣을 수 있고 보기만 하며, 스스로 빠질 수 있습니다. 모르는 사람은 읽을 수 없습니다.

처음 한 번 (주인만):
1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기
2. 빌드 → Authentication → 시작하기 → 로그인 방법 **Google** 사용 설정
3. Authentication → 설정 → 승인된 도메인에 `managepkm-coder.github.io` 추가
4. 빌드 → Firestore Database → 데이터베이스 만들기 (asia-northeast3 서울, 프로덕션 모드)
5. Firestore → 규칙 → [`firestore.rules`](firestore.rules) 내용 붙여넣고 게시 (앱의 *규칙 복사* 버튼)
6. 프로젝트 설정 → 내 앱 → 웹(</>) → 앱 등록 → `firebaseConfig`를 앱의 *Firebase 설정 붙여넣기*에 붙여넣기

그다음: *구글로 로그인* → *내 장부 공유 시작* → *가족 초대 링크 보내기*(7일 유효, Firebase 설정이 링크에 같이 들어가서 받는 사람은 따로 설정할 필요 없음).
받은 사람은 링크를 열고 구글로 로그인하면 **보기만** 하는 모드로 바뀌고, 원래 자기 폰의 장부는 그대로 남습니다(*그만 보기*로 돌아감).
주인이 다른 폰에서 같은 구글 계정으로 *공유 시작*을 누르면 같은 장부를 이어서 씁니다(더 늦게 저장된 쪽이 이김).
Firebase SDK는 `vendor/firebase-12.19.0.mjs`(공식 npm 패키지를 브라우저용으로 묶은 것)이고 공유를 쓸 때만 불러옵니다.

### 백업 파일로 주고받기

실시간 공유 없이 한 번만 옮길 때:
설정 → **백업 파일 저장** → 카톡 등으로 보내기 → 다른 폰에서 **불러오기** 하면 똑같이 보입니다.
브라우저 데이터를 지우면 함께 지워지므로 가끔 백업 파일을 저장해 두세요.

## 보험 내역을 자동으로 불러올 수 없나요?

뱅크샐러드·토스 같은 앱은 금융위원회의 **마이데이터(본인신용정보관리업) 허가**를 받은 회사만 쓸 수 있는 API로 보험사 데이터를 받습니다.
개인이 만든 앱은 이 API에 접근할 수 없어서 자동 연동은 불가능합니다.
대신 [내보험다보여(신용정보원)](https://www.credit4u.or.kr)에서 본인 명의 보험 전체를 무료로 조회해 옮겨 적을 수 있습니다(가족은 각자 본인인증).
